# 干涉與繞射　線上互動教材

高一必修物理「干涉與繞射」（3 節 × 50 分鐘）的線上互動教材。內容整合了原始的 10 份文件（01–08、10），並補齊了缺漏的題目。

## 開啟方式

教材是純前端網頁，不需要安裝套件，也能離線使用。

- **建議做法**：在 `干涉與繞射線上教材` 資料夾執行下面這行，再用瀏覽器開啟 `http://localhost:8770`：
  ```bash
  python -m http.server 8770 --directory app
  ```
- **直接開啟**：雙擊 `app/index.html`。教材全部使用一般 script，不依賴模組載入，Chrome 和 Edge 應該都能直接開。
- **部署**：把整個 `app/` 資料夾放到任何靜態網站空間即可，例如學校主機或 GitHub Pages。

## 功能重點

- **情境式學習**：「光學偵探社」三個案件，每節都依「預測 → 觀察 → 解釋 → CER → 修訂」進行。
- **互動模擬**：
  - 繩波疊加
  - 36 秒疊加動畫
  - 水波干涉（俯視與 3D，可放置觀察點）
  - M02 次波模型
  - 雙狹縫理想模型
  - 單狹縫繞射
  - 薄膜干涉
- **即時回饋**：
  - 選擇題當下回饋，答錯可以再試。
  - 開放題即時顯示關鍵要素覆蓋，供學生自評。
  - 預測一旦送出就鎖定，之後才揭示觀察結果。
- **AI 追問**：依 08 的規則運作，每次只問一個問題、最多 3 句，而且不代答。
  - 提示依 10 的 L1–L3 分層提示；連續兩層仍卡在同一個錯誤時，標記「轉教師」。
  - 預設使用離線規則式追問，不需付費服務。
  - 教師端可另外設定免費的本機語言模型端點（例如 Ollama）；連線失敗時自動改回離線追問。
- **評量**：前測、三節隨堂測驗、後測，共 1 份前測 14 題、3 份隨堂各 7 題、1 份後測 14 題。
  - 自動計分，並依雙向細目表顯示各目標與各認知層次的達成率。
- **學習紀錄**：
  - 以學生代碼作答，存在本機瀏覽器，重新整理可續作。
  - 可下載 JSON、CSV、HTML，共用設備用完可以清除。
- **教師端**：
  - 教案與分節指引、參考答案與成功規準、學習困難引導表、雙向細目表。
  - 匯入多位學生的 JSON 紀錄後，可合併檢視並匯出 CSV。
  - AI 設定、交付檢核清單、投影模式。
- **介面**：支援深色模式與手機版（375px 寬已測試）。

## 修改題目

1. 編輯 `app/js/data/worksheets.js`（學習單）或 `questions.js`（評量）。
2. 執行下面這行。程式會檢查題數、配分與認知層次是否符合 06 規格，並重新產生 `題庫補充.md`：
   ```bash
   node tools/gen-qbank.js
   ```
